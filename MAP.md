# Map

What is in this vault, folder by folder. The agent keeps it current.

- 01-inbox/ — drop anything here; /inbox files it
- 02-subjects/ — what you run: projects, clients, areas
- 03-references/people/ — people you work with
- 03-references/companies/ — companies you deal with
- 04-archive/ — finished subjects and session logs
- preferences/ — how you want each kind of work done
