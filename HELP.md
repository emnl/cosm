# Writing notes

You can just type. The AI tidies up when it files a note. These few things are all you need:

| To | Do |
|---|---|
| Make a new note | ⌘N (it lands in `01-inbox`) |
| Paste an image or drop a file | it lands in `01-inbox`; `/inbox` files it |
| Open any page | ⌘O, then type part of its name |
| Search everything | ⌘⇧F |
| A heading | start the line with `# ` (or `## ` for a smaller one) |
| A list | start the line with `- ` |
| A checkbox | start the line with `- [ ] `; click it to tick |
| Bold | **text** between two stars on each side |
| Link to another page | type `[[` and pick the page |
| Back to the start page | ⌘O → HOME |
| Chat gone from the right | ⌘P → "Toggle chat view" (it also comes back by itself next time Obsidian starts) |

The markup only shows on the line your cursor is on; everywhere else the note looks finished.
